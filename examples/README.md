# Exemplos fictícios

Estes dois arquivos foram criados para demonstrar o Alinha **sem informações de pessoas reais**.

- [Currículo demonstrativo](resume.txt)
- [Descrição de vaga fictícia](job.txt)

Abra o [Alinha Community](../docs/getting-started.md), cole os conteúdos no formulário ou envie o currículo TXT. Você pode ver uma prévia sem IA com o botão **Ver uma demonstração**.

Quando configurar um provedor real, o resultado gerado poderá variar; não compare a classificação com uma nota ATS. O verificador sempre checa se as citações aparecem no texto enviado.
